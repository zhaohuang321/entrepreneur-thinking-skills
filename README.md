## 安装与调用

下载人物 ZIP 并解压，将含 SKILL.md 的整个目录放入 Codex 的 ~/.codex/skills/，重新开启会话。压缩包中的目录名可能与 Skill 名称不同，请保留完整目录与 references。

> 用雷军的视角分析这个产品：目标用户是谁、真实痛点是什么、价值承诺如何落到成本和交付？

> 再用稻盛和夫和段永平的视角比较，给出判断、具体行动、验证方式和失败边界。

提供目标、事实、限制和可承担代价。一次比较2—3个视角，按业务证据选择行动。

## 来源与适用范围

本专区整理已有 Skill，不代表本次重新核查人物的最新观点。各人物的来源、实际阅读范围、研究时间与验证局限见包内文件。模型属于提炼与现代应用，不是本人对现实问题的真实发言，也不保证经营或投资结果。

新生成的20位人物使用有界公开材料版，共57个核心模型；其余12份保留原交付版本与来源范围。方法及部分原始示例来自[女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)，请同时查看原始来源及许可说明。
